# PROMPT PARA CLAUDE — NUEVO SERVICIO DE WEBBSITE LLC: PLATAFORMA DE EDICIÓN DE CONTENIDO PROFESIONAL PARA CLIENTES

Necesito que analices, entiendas y visualices esta nueva idea de negocio para **WEBBSITE LLC**. La intención es crear un nuevo servicio dentro del website de la compañía, donde los clientes puedan registrarse, iniciar sesión, subir videos en crudo y recibir esos mismos videos editados profesionalmente dentro de su propio perfil.

Quiero que pienses esta idea como una plataforma tipo **portal de cliente + sistema de entrega de contenido + servicio mensual de edición profesional para redes sociales**.

---

## 1. Concepto general del negocio

WEBBSITE LLC actualmente ofrece servicios digitales como creación de websites, landing pages, e-commerce, booking sites, mantenimiento web y soluciones digitales para negocios.

Ahora queremos agregar un nuevo servicio:

**Edición profesional de contenido para redes sociales.**

La idea es que los clientes puedan grabar videos simples desde su celular o cámara, subirlos en bruto a su perfil dentro del website de WEBBSITE LLC, y luego nuestro equipo se encargue de editarlos profesionalmente para Instagram, TikTok, YouTube Shorts, Facebook Reels u otras plataformas.

El cliente no tendría que enviar videos por WhatsApp, Google Drive, email o mensajes desorganizados. Todo estaría centralizado dentro de su cuenta en nuestro website.

---

## 2. Diferencia entre visitantes normales y clientes registrados

El website debe tener dos niveles de experiencia:

### A. Visitantes sin iniciar sesión

Las personas que entren al website sin cuenta podrán ver:

* Página principal de WEBBSITE LLC.
* Servicios principales.
* Información de la compañía.
* Portafolio.
* Planes y precios.
* Botones para agendar llamada.
* Botones para comprar o solicitar servicios.
* Información general del servicio de edición de contenido.
* Formulario de contacto.

Estas personas todavía no tienen acceso al sistema interno.

---

### B. Clientes con cuenta / perfil

Los clientes que ya hayan comprado o contratado un servicio podrán:

* Crear una cuenta.
* Iniciar sesión.
* Acceder a un dashboard privado.
* Ver sus servicios activos.
* Subir videos en crudo.
* Escribir instrucciones para cada video.
* Ver el estado de cada video.
* Descargar los videos editados.
* Solicitar revisiones.
* Ver historial de trabajos entregados.
* Comunicarse con WEBBSITE LLC dentro de su perfil.
* Ver facturación, pagos o plan activo.
* Acceder a recursos, recomendaciones y guías.

El objetivo es que el cliente sienta que tiene un portal profesional propio dentro de WEBBSITE LLC.

---

## 3. Flujo principal del cliente

Quiero que visualices el flujo de esta forma:

### Paso 1: El cliente entra al website

El cliente visita el website de WEBBSITE LLC y ve los servicios disponibles.

Uno de los servicios destacados será:

**“Professional Social Media Content Editing”**
o
**“Edición Profesional de Contenido para Redes Sociales”**

---

### Paso 2: El cliente compra o solicita el servicio

El cliente puede escoger entre diferentes planes, por ejemplo:

* Edición por video individual.
* Plan mensual básico.
* Plan mensual profesional.
* Plan mensual premium.
* Paquete para negocios.
* Paquete para creadores de contenido.
* Paquete para marcas personales.

Después de pagar o ser aprobado manualmente por WEBBSITE LLC, se le crea acceso al portal.

---

### Paso 3: El cliente crea su perfil o inicia sesión

El cliente podrá iniciar sesión con:

* Email y contraseña.
* Google login, si se implementa.
* Posiblemente magic link en el futuro.

Después de iniciar sesión, entra a su dashboard privado.

---

### Paso 4: El cliente sube videos en crudo

Dentro de su dashboard, el cliente verá una sección que diga:

**Upload Raw Content**
o
**Subir Videos en Crudo**

Ahí podrá subir:

* Videos desde celular.
* Videos horizontales.
* Videos verticales.
* Archivos pesados.
* Clips cortos.
* Videos de 30 segundos a varios minutos.
* Audios o recursos adicionales.
* Logos, imágenes o branding del cliente.

Cada video subido debe guardarse en la nube, conectado al perfil de ese cliente.

---

### Paso 5: El cliente llena instrucciones para el video

Después de subir el video, el cliente debe poder llenar un formulario con detalles como:

* Título del video.
* Plataforma donde lo quiere usar: Instagram, TikTok, YouTube Shorts, Facebook, LinkedIn, etc.
* Formato deseado: vertical 9:16, horizontal 16:9, cuadrado 1:1.
* Estilo de edición: elegante, dinámico, corporativo, viral, educativo, lujo, real estate, fitness, podcast, etc.
* Idioma de los subtítulos.
* Si quiere música de fondo.
* Si quiere cortes rápidos.
* Si quiere zooms.
* Si quiere transiciones.
* Si quiere emojis o no.
* Si quiere captions profesionales.
* Si quiere branding de su empresa.
* Fecha límite deseada.
* Notas adicionales.

Esto nos permite entender exactamente qué tipo de edición necesita.

## 6. Flujo interno de trabajo para WEBBSITE LLC

Cuando un cliente sube un video:

1. El sistema recibe el archivo.
2. El archivo se guarda en la nube.
3. El proyecto aparece en el panel interno.
4. WEBBSITE LLC revisa las instrucciones.
5. Se asigna el trabajo a un editor o sistema de edición.
6. El video se edita profesionalmente.
7. El video editado se sube al perfil del cliente.
8. El cliente recibe una notificación.
9. El cliente revisa y descarga.
10. Si necesita cambios, solicita revisión.
11. WEBBSITE LLC realiza la revisión.
12. El proyecto queda marcado como completado.
